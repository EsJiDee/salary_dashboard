## 📝 Project Overview

This project features a Data Professional Salary Dashboard analyzing global job postings. It explores median salary variations across specific titles, countries, schedule types, and platforms to uncover key compensation trends in the tech and data industry.

## 📂 Repository Contents

*   **Project 1 Salary Dashboard.xlsx**: The main Excel workbook containing the raw dataset, data cleaning steps, pivot tables, and the interactive visual dashboard.

## 📈 Key Insights & Features

1.  **Salary by Job Title**: Compares median compensation for Data Analysts, Data Scientists, Data Engineers, and other related roles.
2.  **Geographic Trends**: Highlights which countries offer the most competitive salaries for data professionals.
3.  **Schedule Impact**: Analyzes how schedule types (e.g., Full-time, Part-time, Contract) influence expected pay.
4.  **Platform Sourcing**: Tracks variations in salary based on the platform where the job was posted.

## 🚀 How to Use

1.  Download or clone this repository to your local machine.
2.  Open **Project 1 Salary Dashboard.xlsx** using Microsoft Excel.
3.  Navigate to the "Salary_Dashboard" tab to interact with the visualizations.
4.  Use the provided slicers (filters) to drill down into specific job titles, countries, or work schedules.

*   **Microsoft Excel**: For data cleaning, pivot tables, and dashboard creation.
